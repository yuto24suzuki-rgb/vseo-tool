# 企画書:しおたん × 与那覇院長「渋谷院 潜入ツアー」

**対象:** URARAクリニック 渋谷院(2026年9月1日開院)
**出演:** しおたん × 与那覇院長
**作成日:** 2026年7月28日

---

## 1. 企画概要

> **「渋谷駅から歩いて、できたばかりの渋谷院に潜入。院長のこだわりを全部見せてもらう」**

しおたんさんと与那覇院長が渋谷駅で待ち合わせ、クリニックまで実際に歩いて移動し、そのまま院内を紹介する1本。これ1回の撮影で以下を全て回収する。

| 回収できる要素 | 対応 |
|---|---|
| 駅からの動線(行き方) | 移動パートがそのまま道案内コンテンツになる |
| 院内・設備の紹介 | 院内ツアーパート |
| 「与那覇先生のこだわり」という見せ方 | 図面・機器を小道具に、単なる内装紹介ではなく「人のこだわり」の物語にする |
| モニター募集の告知 | エンディング+概要欄で告知(医療広告ガイドライン準拠の形) |

**この企画が強い理由**
- 単体の「行き方動画」「ルームツアー」より、**しおたんさんという視聴者側の目線+院長という中の人**の掛け合わせで最後まで見られる構成にできる(視聴維持率)。
- 「与那覇先生がこだわった図面・機器」という切り口は、**設備自慢ではなく人の物語**になるため、医療広告ガイドライン的にも安全な訴求軸。
- 1回の撮影日で YouTube本編1本+ショート/リール5〜6本を撮り切れるため、撮影が開院後に限られる制約下で効率が最も高い。

## 2. YouTube版:本編構成案(10〜12分)

**タイトル案**
- 「【初公開】渋谷駅から歩いて何分?できたばかりのURARA渋谷院に潜入したら院長のこだわりがすごかった」
- 「【密着】オープンしたての渋谷院、院長と一緒に駅から行ってみた」

**VSEO設計:** タイトル・概要欄に「渋谷 医療ダイエット」「渋谷 医療痩身」「URARAクリニック 渋谷」を含める(ツールで抽出したキーワードを反映)。

| シーン | 時間 | 内容 | 演出ポイント |
|---|---|---|---|
| ① OP | 0:00–0:30 | 渋谷駅ハチ公口で2人が合流。「9/1にオープンしたばかりの渋谷院に、今日は院長と一緒に行きます」 | 冒頭で「駅から徒歩何分か検証」のフックを立てる(タイマー表示) |
| ② 移動 | 0:30–2:30 | 実際のルートを歩きながら雑談。しおたんさんが院長に「なんで渋谷に出したんですか?」を聞く | 曲がり角ごとにランドマークをテロップ表示(=そのまま道案内として機能)。タイマーで「徒歩○分」を計測 |
| ③ 到着 | 2:30–3:30 | ビル到着→エントランス→受付。「ついた!徒歩○分!」 | ビル外観・入口・フロアを明確に見せる(来院時の不安解消) |
| ④ 院内ツアー | 3:30–8:00 | 受付→カウンセリングルーム→施術室を院長が案内。**各所で「与那覇先生のこだわりポイント」を発表**(例:3つのこだわり) | **A1印刷した図面を小道具に**「ここは図面の段階からこだわった」と語らせる。しおたんさんはツッコミ・リアクション役 |
| ⑤ 機器体験 | 8:00–10:00 | 院長イチオシの機器1つをしおたんさんが体験 | 「なぜこの機器を渋谷院に入れたのか」を院長が解説(こだわり文脈の続き) |
| ⑥ ED+告知 | 10:00–11:30 | まとめ→**「渋谷院 開院記念モニターを募集します」**→概要欄へ誘導 | 料金は通常料金とモニター料金を併記。「今だけ○%オフ」等の表現は使わない(後述) |

**サムネイル案:** エントランス前で2人。コピー「渋谷駅から徒歩○分」「院長のこだわりがすごい」

**切り出しショート(本編撮影から同時生成)**
1. 行き方60秒版(②③を縦型で再編集)
2. 院長のこだわり1個ずつ(④から)×2〜3本
3. 機器体験ダイジェスト(⑤から)
4. モニター募集告知(⑥から)

## 3. Instagram版:同一素材からの展開案

同じ撮影日の素材+スマホ別撮りで、リール中心に分解して展開する。

| # | フォーマット | 内容 | 狙い |
|---|---|---|---|
| IG-1 | リール(30〜45秒) | 「渋谷駅から○分で着く医療痩身クリニック」道案内特化版。テキストオーバーレイでルートを表示 | **保存されるコンテンツ**(来院予定者が見返す)。位置情報タグ必須 |
| IG-2 | リール(30秒) | 「与那覇院長のこだわり3選」テンポよく3カット | こだわり軸の認知拡散 |
| IG-3 | リール(30〜45秒) | 「しおたんが新しい機器を体験してみた」リアクション中心 | エンタメ枠。しおたんさん側アカウントとのコラボ投稿(Collab機能)でリーチ拡張 |
| IG-4 | フィード(カルーセル) | 院内写真8〜10枚+各所のこだわり解説テキスト | 保存用・指名検索後の受け皿 |
| IG-5 | ストーリーズ | 撮影オフショット/質問箱「渋谷院に聞きたいこと」/モニター募集(リンクスタンプでLPへ) | 日次の接触+応募導線 |
| IG-6 | ピン留め | IG-1(行き方)とモニター募集投稿をプロフィール上部に固定 | プロフィール来訪者を逃さない |

**運用メモ**
- リールはYouTubeショートの転載ではなく、Instagram向けにテキスト量を増やして再編集(保存率が伸びやすい)。
- しおたんさん出演分は**コラボ投稿(共同投稿者設定)**にして両アカウントのフォロワーに同時リーチさせる。
- 公開ペースは週2本を上限に分散し、9月中の接触頻度を維持する。

## 4. モニター募集告知の載せ方(医療広告ガイドライン対応)

動画・投稿内での取り扱いは以下に統一する。

| | 表現 |
|---|---|
| OK | 「渋谷院開院記念モニターを○名募集します。通常料金○○円のところ、モニター料金○○円です。詳細・応募条件は概要欄をご覧ください」 |
| NG | 「今だけ半額!」「オープン記念○%オフ!」「先着プレゼント」等の費用強調・誘引表現 |

**概要欄・キャプション記載テンプレ(必須項目)**
1. 施術名・内容
2. 通常料金とモニター料金の併記
3. リスク・副作用
4. 応募条件(症例写真・映像の利用同意を含む)
5. 応募導線(LP または LINE)
