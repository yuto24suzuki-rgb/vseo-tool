## 2. リサーチサマリー:開院前にクリニック・店舗が行っている施策

世の中のクリニック開業・新店舗オープンの成功事例を横断調査した結果、効果が報告されている施策は大きく5類型に整理できる。

### ① 開院前からの「プロセス共有」でファンの事前獲得
- 開業前からSNSで準備過程を発信し続けた店舗では、来店客から「オープン前からSNSを見てました」という声が多数上がり、初日からのスタートダッシュに成功した事例が複数報告されている。
- ポイントは「完成形を見せる」のではなく「できていく過程・中の人・想い」を見せること。オープン前の情報の希少性が高いため、平常運転の投稿よりエンゲージメントが高くなりやすい。

### ② 医師・スタッフの「人」を前面に出した発信
- 近年のクリニック集患では、医師個人の専門性・経歴・診療への想いをSNSで発信することが信頼獲得に最も効くとされる。
- 美容医療業界では共立美容外科「共立ドキュメンタリー」、TCBの密着企画、『整形GoodDoctor』(ザ・ノンフィクション前CPが制作)など、**ドキュメンタリー形式のYouTube企画**が定着しており、新規開業医師への密着(例:Dr.紀田/2025年7月開業THE BEAUTE CLINIC)は開業認知の起爆剤として機能している。

### ③ 内覧会(オープン前後のお披露目イベント)
- クリニック開業のセオリーとして、開業1週間前の土日に内覧会を実施するのが最も効果的とされ、早期の口コミ形成に直結する。
- 一般向け内覧会を実施しない場合でも、**インフルエンサー・提携メディア向けの内覧(レセプション)** に置き換えることでUGC(第三者発信)を初日に集中させる手法が美容業界では一般的。

### ④ オープン記念オファー(※医療広告ガイドラインの制約あり)
- 一般店舗では「オープン記念○%オフ」「先着プレゼント」が定番だが、**医療機関では「今だけ○%オフ」等の費用強調・品位を損なう広告、来院プレゼント等の誘引は違反**となる。
- 一方、**モニター募集(モニター料金と通常料金の併記)は禁止されていない**。美容クリニックの新規開業では「開院記念モニター募集」が事実上の標準施策になっている。
- 患者の体験談・ビフォーアフターは、クリニックが関与する形でのSNS掲載は原則NG(ビフォーアフターは施術内容・費用・リスク等の詳細併記など限定条件下でHP掲載可)。

### ⑤ 検索・地図経路の事前整備(オーガニックの受け皿)
- 開業成功例のロードマップでは、開業半年前〜のWebサイト/Googleビジネスプロフィール(MEO)/SNSアカウント整備が標準。SNSで認知した人は「URARAクリニック 渋谷」で指名検索するため、**検索結果とマップの受け皿が開院告知前に整っていることが前提条件**になる。
- YouTubeはストック型のため、「渋谷 医療ダイエット」「渋谷 痩身」等のVSEOキーワードを含む動画を開院前後に仕込むことで、開院後の継続的な指名外流入をつくれる。

## 3. 提案の全体設計:3フェーズ構成

「開院前は院内撮影不可」という制約を逆手に取り、**「見せられないからこそ期待感を煽るティザー期」→「開院直後に一気に見せるリビール期」**の2段構成でエンゲージメントの山を9/1に集中させる設計とする。

```
Phase 0(〜8月上旬)   仕込み:アカウント・素材・法務・撮影段取りの準備
Phase 1(8月中旬〜8/31) ティザー:撮影素材なしで期待感を最大化
Phase 2(9/1〜9月末)   リビール:院内コンテンツを一気に投下+モニター募集で刈り取り
```

## 4. 【最重要提案】渋谷院オープン記念「密着ドキュメンタリー × モニター募集」企画

リサーチ結果(②人を見せるドキュメンタリーが認知の起爆剤/④医療機関で合法的に使える唯一の強いオファーがモニター募集)を掛け合わせた、以下の企画を最も効果が高い施策として提案する。

### 企画概要
> **「渋谷院オープンまでの舞台裏、全部見せます」**
> 渋谷院の院長・スタッフに8月から密着し、開院準備の裏側をYouTube本編+ショート/リールで連載。最終回=開院初日の完全密着。並行して「渋谷院開院記念モニター」を募集し、ドキュメンタリーの視聴者をモニター応募に着地させる。

### なぜこれが最も効果的か
1. **制約と完全に整合する:** 密着の主役は「場所」ではなく「人」。8月中は既存院(新宿・銀座)でのインタビュー・準備風景・ミーティング等で撮影でき、院内撮影不可の制約を受けない。院内は9/1以降の「リビール」として最大の見せ場に温存できる。
2. **業界で再現性が実証されている:** 共立・TCB・Dr.紀田など、美容医療のドキュメンタリー/密着はチャンネル成長と開業認知の両方で成果が出ている型。
3. **オファーとして合法かつ強い:** 「オープン○%オフ」が使えない医療機関において、モニター募集は費用メリットを合法的に提示できるほぼ唯一の手段。かつモニター契約により症例写真の同意取得が進むため、**開院後の症例コンテンツ資産づくりを兼ねる**。
4. **URARAの既存文脈と接続できる:** 医療痩身は「経過を追う」ジャンルであり、しおたん氏タイアップ等「変化を見せる」既存コンテンツと相性が良い。モニター1期生の経過連載として開院後の運用にそのまま接続できる。

## 7. 医療広告ガイドライン上の注意点(キャンペーン設計の前提)

| 項目 | 可否 | 備考 |
|---|---|---|
| モニター募集(モニター料金と通常料金の併記) | ○ | 開院記念オファーの主軸に据える |
| 「今だけ○%オフ」等の費用強調キャンペーン | × | 品位を損ねる広告として違反 |
| 「来院された方に○○プレゼント」 | × | 治療と無関係な誘引で違反 |
| 患者体験談のクリニック側SNS掲載 | × | 誘引性が認められる場合は事実でも不可 |
| ビフォーアフター | △ | 施術内容・費用・リスク副作用等の詳細併記など限定条件下で可。事前のモニター同意が必須 |

※ 個別の投稿クリエイティブは配信前にガイドラインチェックを行う運用とする。

## 8. 開院前に先方へ連携をお願いしたい事項

撮影に入れない代わりに、以下の**素材提供・段取り**を先方(現場担当者)にお願いしたい。

1. **内装パース・完成予想図・図面**の提供(設計会社保有のもの。ティザー投稿1-3で使用)
2. **工事中・内装工事完了時の写真/スマホ動画**(現場担当者のスマホ撮影で可。数枚〜数十秒で十分)
3. **開院後できるだけ早い撮影日の確保**(理想:9/1初日に密着撮影。難しければ開院前日の竣工チェック・内覧タイミングに1枠でも入れれば#3が成立)
4. **院長・渋谷院スタッフの出演可否とアサイン**(8月中の既存院でのインタビュー撮影1〜2回)
5. **モニター企画の要項確定**(対象施術・枠数・料金・症例利用同意書)※法務確認含め8月上旬までに
6. **ビル外観・共用部の撮影可否確認**(ビル管理会社への申請。行き方動画1-4のため)
7. **Googleビジネスプロフィール登録用情報**(正式名称・住所・電話・診療時間・URL)
8. **9月分の事前予約受付の可否と開始日**(SNSのCTA設計に直結)
