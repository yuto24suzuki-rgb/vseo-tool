# MEMOTO CLINIC YouTube提案 パワポ資料化用テキスト

作成日: 2026-07-28
用途: クライアント提案用パワーポイント。各スライドに貼り付ける文章+根拠+要準備事項。

構成: ①レッドオーシャン → ②差別化なしでは伸びない → ③伸びるフォーマット(50・60代訴求) → ④完全特化は不在(+アップセル) → ⑤院長の実体験と「寄り添う」テーマ → ⑥チャンネルコンセプト → ⑦〜⑩企画案4本 → ⑪制作フロー

## スライド① クマ治療業界はレッドオーシャンである

**スライドタイトル案**: 「クマ取り」はYouTube美容医療の最激戦区

**キーメッセージ(1行)**:
YouTube上のクマ治療は、大手から個人医師まで参入しきった"レッドオーシャン"です。

- 症例数・価格・術式の訴求はすでに出尽くしており、同じ訴求で後発が参入しても埋もれるだけの市場

## スライド② 差別化なしでは伸びない(現状の課題)

**スライドタイトル案**: 現状は、そのレッドオーシャンに"丸腰"で挑んでいる

**キーメッセージ(1行)**:
現状のチャンネルは競合と同じ土俵・同じ見せ方であり、後発が同質化したまま戦っても構造的に伸びません。

**本文(貼り付け用)**:
- 現状の動画は、タイトル・サムネイル・企画の方向性が先行競合とほぼ同じ(=視聴者から見て「見分けがつかない」)
- YouTubeのアルゴリズムは「そのジャンルの既存有力チャンネル」を優先的に露出するため、同質コンテンツの後発は推薦面でも不利
- 問題は動画のクオリティではなく、「選ばれる理由(ポジション)」が設計されていないこと
- → 必要なのは「もっと頑張る」ではなく「戦う場所を変える」こと

**掲載するデータ**: 現状チャンネルの登録者数・直近10本の再生数の推移グラフ/競合とのサムネ比較(並べて掲載)

**要準備**: YouTube Studioから現状数値とスクリーンショットを取得

## スライド④ 完全に50・60代をターゲットにしたクリニックは存在しない

**スライドタイトル案**: 「単発」はあっても、「専門」はいない

**キーメッセージ(1行)**:
50・60代向け動画は各チャンネルの"単発企画"止まり。チャンネル全体をこの層に捧げているクリニックはまだ存在しません。

**本文(貼り付け用)**:
- スライド③の11本は、すべて「別々のチャンネルがたまに出す単発企画」。つまり各社とも"伸びる"ことに気づきながら、主戦場は20〜40代のまま
- 最もシニア寄りの銀座みゆき通り美容外科(40代以上に強い)ですら、軸は「実録・他院修正」であり「年齢特化」ではない
- ここに「チャンネルまるごと50・60代特化」で参入すれば、このセグメントの検索結果・関連動画を独占できる

**補足(収益性の裏付け)**:
- 50・60代のクマは「脂肪+たるみ+骨格」の複合問題のため、脱脂単体で終わらず眉下切開・切開ハムラ・たるみ治療など複合治療への展開が自然に成立しやすい
- 実際に競合でも「60代は眉下切開/切開ハムラ同時手術」という企画が成立している(スライド③の動画8)
- 若年層=脱脂単価のみで価格競争、50・60代=複合治療で客単価が高い。少ない再生数でも経営インパクトが出る層

**掲載する図**: ポジショニングマップ(縦軸: 若年層⇔シニア、横軸: テクニック・症例⇔不安解消・伴走)。右下が空白であることを示し「★MEMOTO」を置く

**要準備**: MEMOTOの料金表で客単価モデルケース試算(50代: 脱脂+裏ハムラ+眉下切開 vs 20代: 脱脂のみ)

## スライド⑤ 大路先生自身の実体験 — 「教える」ではなく「寄り添う」

**スライドタイトル案**: この空白を取れる、唯一無二の語り手がいる

**キーメッセージ(1行)**:
大路先生自身が美容整形で大きく変わった経験を持つからこそ、「教える医師」ではなく「寄り添う医師」という他院にない立ち位置が取れます。

**本文(貼り付け用)**:
- 鈴木大路院長は、容姿へのコンプレックスから自身が美容整形を受け、見た目が大きく変化した実体験を持つ。それが美容外科医を志した原点(名医のチョイス取材記事より)
- 競合チャンネルは全員「教える医師」(上から専門知識を解説する構図)。実体験を持つ大路先生だけが「患者と同じ側に立ったことがある医師」として"寄り添う"構図を取れる
- 「はじめての美容医療が怖い」という50・60代の心理に対し、「僕もそうでした」から始められる語り手は模倣不可能
- 経歴の裏付け: 名古屋大学医学部卒 → 豊田厚生病院 → 大手美容外科3院(岐阜・金沢・浜松)院長歴任 → 2024年7月MEMOTO開院。目元症例6,000件以上(2020年4月〜2025年4月)

**トーン設計(「寄り添う」の具体化)**:
- ×「この施術はこうです」 → ○「不安ですよね。僕も手術前の夜は眠れませんでした」
- ×専門用語で解説 → ○患者の言葉に言い換える(経結膜脱脂→「まぶたの裏から脂肪を取る、切らない治療」)
- ×売り込み → ○「やらない方がいい人」も正直に言う

**要準備**: 院長ご本人の許可を得て、変化のエピソード(可能ならビフォーアフター)を1枚に

## スライド⑥ チャンネルコンセプト

**スライドタイトル案**: コンセプト — 「50代からの、はじめての目元医療。」

**キーメッセージ(1行)**:
これまで美容医療を行ってこなかった人が、50・60代で初めてクマ治療に踏み出すためのチャンネルを設計します。

**本文(貼り付け用)**:
> **「50代からの、はじめての目元医療。」**
> 自身も整形を経験した目元専門医が、50代・60代ではじめて美容医療を考えるあなたの不安に、ひとつずつ寄り添うチャンネル。

- ターゲット: 美容医療未経験の50・60代(「整形」という言葉に抵抗がある層)
- 提供価値: 施術知識ではなく「一歩踏み出すための安心」
- 設計原則:
  - 症例・サムネイルは50・60代のみ(若い症例は出さない)
  - 全動画フルテロップ・大きい文字・ゆっくりした話速(スマホ+老眼を想定)
  - 「治療前の不安」(費用・家族への伝え方・ダウンタイム・この歳でやっていいのか)を主戦場にする
- 成果指標: 登録者数ではなく「YouTube経由の50・60代初診カウンセリング数」を最上位KPIに置く

## スライド⑦ 企画案① 「はじめてのクマ治療」まるわかりシリーズ

**役割**: 検索流入の入口(VSEO軸)。「クマ取り 50代」等の悩み検索を刈り取る、チャンネルの土台

**企画概要(貼り付け用)**:
50・60代が検索する不安・疑問に、1本1テーマで答える基礎シリーズ。タイトル冒頭に検索キーワードを置き、検索結果でこのチャンネルが「50・60代の指定席」になる状態を作る。

**タイトル例**:
- 【50代のクマ取り】治療を考え始めたら最初に見る動画(完全ガイド)
- 60代でもクマ取りはできますか?目元専門医が正直に答えます
- クマ取りの費用はいくら?相場と「安さで選ぶ危険」を解説
- ダウンタイムは何日?仕事・家事はいつから?【年代別に解説】
- 60代の目の下治療、持病・服薬があっても受けられる?
- 家族に反対されたら?美容医療と家族の話

**狙うキーワード**: クマ取り 50代/クマ取り 60代/目の下のたるみ 50代/切らないクマ取り/クマ取り 失敗・後悔

## スライド⑧ 企画案② 同世代症例シリーズ「50代・60代のクマはこう変わる」

**役割**: 「自分と同じ人が受けている」という安心の醸成。来院意思決定の決め手

**企画概要(貼り付け用)**:
症例解説をすべて50・60代に限定したシリーズ。年齢・悩みの背景(「孫に怖い顔と言われた」等)から治療選択の理由、経過までをストーリーで見せる。50・60代のクマは脂肪+たるみ+骨格の複合問題であり、裏ハムラまで扱える当院の技術的優位性が自然に伝わる。

**タイトル例**:
- 【症例解説】58歳女性・はじめての美容医療。目の下はこう変わる
- 【症例解説】62歳女性「孫に怖い顔と言われて」— 治療選択の理由
- 50代と20代でクマ治療は何が違う?症例で比較解説
- 【正直解説】この方には脱脂を勧めませんでした — その理由
- 治療1週間後・1ヶ月後・3ヶ月後、経過を全部見せます

**留意**: 医療広告ガイドライン対応(施術内容・費用・リスク副作用を動画内+概要欄に必ず併記)

## スライド⑨ 企画案③ 密着ドキュメント「美容医療デビューの一日」

**役割**: 来院ハードルの最終解除。カウンセリング〜帰宅までを可視化し「知らない場所への恐怖」をなくす

**企画概要(貼り付け用)**:
50・60代の患者様(同意取得)の美容医療デビューに密着。受付・カウンセリング・施術当日・帰宅までの流れを丸ごと見せる。競合の密着が「変化のビフォーアフター」を主役にするのに対し、本企画は「不安が解けていく過程」を主役にする(=寄り添いテーマの映像化)。

**タイトル例**:
- 【密着】55歳・美容医療デビューの一日(カウンセリング〜帰宅まで)
- カウンセリングを丸ごと公開。医師は何を見て診断しているのか
- 手術当日の流れを全部見せます【不安な方はこれを見てから】
- 名古屋駅から徒歩2分。院内をすべてご案内します

**留意**: 患者出演は「当日の流れ」等の事実描写に留め、治療効果の体験談は語らせない(広告規制対応)

## スライド⑩ 企画案④ 院長ストーリー「整形した美容外科医」

**役割**: チャンネルの旗印。差別化の核であり、全動画から導線を張る"チャンネルの存在理由"

**企画概要(貼り付け用)**:
大路先生自身の整形経験・コンプレックス・変化を正面から語るシリーズ。初期に公開してチャンネルの世界観を宣言し、チャンネル紹介動画・全動画の固定コメントから常時導線を張る。「寄り添う」というテーマを言葉ではなく人生で証明する企画。

**タイトル例**:
- 【告白】美容外科医の僕自身が、整形した側の人間です
- なぜ小児科医から美容外科医に?僕が目元専門になった理由
- コンプレックスは「我慢するもの」じゃない — 50代からの選択肢
- 僕が「やらない方がいい」と伝える時 — 断る美容外科医の話

**留意**: 医師本人の経歴・動機として語るのは広告規制上も可。ただし「だからあなたも効果が出る」という誘引表現にはしない

## スライド⑪ 制作フロー(クライアント工数)

**スライドタイトル案**: 院長の拘束は「月1回・半日」だけ

**キーメッセージ(1行)**:
企画・編集・投稿・分析は運用側が巻き取り、クリニック側の工数は撮影と監修のみに絞ります。

**制作フロー(貼り付け用)**:

| 工程 | 担当 | クライアント工数 |
|---|---|---|
| 1. 企画立案(VSEOデータから企画書作成) | 運用側 | なし |
| 2. 企画監修・採否決定 | 院長 | 月30分(オンライン可) |
| 3. 撮影(月1回まとめ撮りで4〜6本収録) | 運用側+院長 | 月1回・半日 |
| 4. 編集・テロップ・サムネイル制作 | 運用側 | なし |
| 5. 医療広告ガイドラインチェック | 運用側→院長最終確認 | 1本あたり10〜15分 |
| 6. 投稿・概要欄・タグ設定 | 運用側 | なし |
| 7. 分析・翌月企画への反映 | 運用側 | 月次報告30分 |

**投稿ペース**: ロング週1本+ショート週3本(ショートはロングの切り出しが中心のため追加撮影なし)

**クライアント工数まとめ(月あたり)**:
- 撮影: 半日×1回
- 企画監修+公開前チェック+月次報告: 合計2時間程度
- → **院長の負担は月合計1日以下。継続できる体制が、この戦略の最重要KPI**
