# MEMOTO CLINIC 名古屋 YouTubeチャンネル戦略提案書

作成日: 2026-07-28

- 対象クリニック: [MEMOTO CLINIC 名古屋](https://nagoya-memoto.jp/)(名古屋駅徒歩2分・目元専門)
- 対象チャンネル: [公式MEMOTO CLINIC](https://www.youtube.com/@%E5%85%AC%E5%BC%8FMEMOTOCLINIC)
- 提案コンセプト: **「50代・60代、はじめての美容医療」に完全特化した目元チャンネル**

---

## 1. 与件の整理

| 項目 | 内容 |
|---|---|
| 市場環境 | YouTube上のクマ治療(クマ取り)分野はレッドオーシャン |
| 勝ち筋 | 競合と異なるポジショニング or 個別性(医師の人格・ストーリー)の打ち出し |
| 市場の穴 | 50〜60代向けのクマ治療発信は伸びやすいが、この年齢層に**特化**した発信者は現状ほぼ不在 |
| クリニックの資産 | 鈴木大路院長自身が、容姿のコンプレックスから美容整形を受けた実体験を持ち、それが美容外科医の原点になっている |
| 結論 | 「50〜60代で、クマ治療・美容医療を**はじめて**受ける人」に向けたチャンネルを立ち上げる |

### クリニック・院長の強み(リサーチ結果)

- 東海地方では希少な**目元特化クリニック**。目元症例数6,000件以上(2020年4月〜2025年4月)
- 切らないクマ取り(経結膜脱脂)、裏ハムラ法など、50〜60代に必要な「たるみ・骨格変化まで対応できる」術式ラインナップを保有
- 鈴木大路院長: 名古屋大学医学部卒 → 豊田厚生病院 → 大手美容外科で岐阜院・金沢院・浜松院の院長を歴任、二重埋没法指導医 → 2024年7月開院
- **院長自身に美容整形の実体験がある** = 「受ける側の不安が分かる医師」という、他院が模倣できない一次情報

## 2. 競合分析:クマ取りYouTubeの現在地

### 主要競合チャンネル

| チャンネル | 特徴 | 主なターゲット |
|---|---|---|
| クマ取りナビ/湘南美容クリニック | 大手の物量・ブランド力。密着系 | 20〜40代中心 |
| 美容整形のりチャンネル(則本医師) | 「クマ取り名人」の個人ブランディング | 20〜40代 |
| Dr.稲富(形成外科専門医) | 裏ハムラ・根本治療の専門性訴求 | 30〜50代 |
| Pono clinic 芝院長 | 院長個人のクマ取り特化 | 20〜40代 |
| 銀座みゆき通り美容外科 | クマ取り歴30年・**40代以上に強い**。カウンセリング実録系 | 40代〜 |
| シンシア Dr.又吉 | 他院修正・解説系 | 30〜50代 |

### 分析から見える市場の空白

1. **「若年層向けの美容トーン」が支配的。** 既存チャンネルの大半は、テンポの速い編集・若い症例・美容リテラシー前提の用語で作られており、50〜60代の初心者には心理的ハードルが高い。
2. **銀座みゆき通りが唯一シニア寄りだが、東京・「治療実録」型。** 「はじめての人の不安に寄り添う教育・伴走」型のポジションは空いている。東海圏では完全に空白。
3. **50〜60代は検索起点でYouTubeを見る。** トレンド消費ではなく「目の下のたるみ 60代」「クマ取り 失敗」のような悩み検索で流入するため、VSEO(YouTube検索最適化)と相性が良く、動画が資産化しやすい。
4. **50〜60代のクマは「色」ではなく「たるみ+骨格+脂肪」の複合問題。** 脱脂だけでなく裏ハムラ等まで語れる医師でないと本質的な発信ができない = MEMOTOの術式ラインナップが参入障壁になる。

## 3. ポジショニング提案

### チャンネルコンセプト

> **「50代からの、はじめての目元医療。」**
> 自身も整形を経験した目元専門医が、50代・60代ではじめて美容医療を考えるあなたの不安に、ひとつずつ答えるチャンネル。

### ポジショニングマップ

```
                若年層向け
                    │
   湘南クマ取りナビ │ のりチャンネル
   Pono芝院長       │ Dr.又吉
                    │
テクニック・症例 ───┼─── 不安解消・伴走
                    │
   Dr.稲富          │  ★MEMOTO(本提案)
   銀座みゆき通り   │  「はじめての人の
                    │   最初の一本」
                シニア向け
```

### 差別化の3本柱

1. **年齢特化**: 全ての動画を「50〜60代の悩み・症例・生活文脈」で作る。サムネの症例も50〜60代のみ。若い症例は原則出さない。
2. **「はじめて」特化**: カウンセリングの流れ、費用の考え方、家族への伝え方、ダウンタイム中の過ごし方など、「治療前の不安」を主戦場にする。競合は「術式の優劣」を戦場にしており、ここが空いている。
3. **院長の実体験**: 「僕自身、コンプレックスで整形した側の人間です」という語りは、体験談規制に抵触しない医師自身の一次情報であり、最強の信頼装置。チャンネルの縦軸ストーリーにする。

## 4. ターゲットペルソナ

### ペルソナA: 佐藤さん(56歳・女性・パート勤務・名古屋市郊外)

- 悩み: 5年前から目の下のたるみとクマで「疲れてる?」と言われる。写真の自分に落ち込む
- 美容医療経験: ゼロ。「整形」という言葉に抵抗があり、家族に言えるか不安
- 情報行動: スマホでYouTube検索「目の下 たるみ 取りたい 50代」。長い動画も座って最後まで見る
- 意思決定: 慎重。3ヶ月〜1年かけて複数動画を見て、失敗例・費用・先生の人柄で決める

### ペルソナB: 田中さん(63歳・女性・孫あり・退職後)

- 悩み: 「不機嫌そう」「怖い顔」と言われる目の下の影。老けたのではなく疲れて見えるのが嫌
- 懸念: 「この歳でやっていいのか」「手術に体が耐えられるか」「不自然になったら?」
- 刺さる訴求: 同年代の症例、施術当日の流れの可視化、医師が正直にリスクを話す姿勢

### ペルソナ共通のコンテンツ設計指針

- 専門用語は必ず言い換える(経結膜脱脂 → 「まぶたの裏側から脂肪を取る、切らない治療」)
- 字幕は大きく、話速はゆっくり、BGM控えめ。1動画1テーマ
- 「やらない方がいい人」「当院でできないこと」を正直に言う動画を意図的に混ぜ、信頼を積む

## 5. コンテンツ戦略

### 動画の4本柱

| 柱 | 役割 | 比率目安 |
|---|---|---|
| ① 不安解消・基礎知識(VSEO軸) | 検索流入の入口。「50代 クマ取り」等の悩み検索を刈り取る | 40% |
| ② 50〜60代症例解説 | 「自分と同じ人が受けている」という安心。CVの決め手 | 25% |
| ③ 密着・カウンセリング実録 | 当日の流れ・院内・スタッフを見せて来院ハードルを下げる | 20% |
| ④ 院長ストーリー・人柄 | 差別化の核。整形経験、なぜ目元専門医になったか | 15% |

6. ダウンタイムは何日?仕事・家事はいつから?【年代別に解説】
7. クマ取りで失敗する人の共通点3つ【50代・60代は特に注意】

### ショート動画戦略

- 週3本目安。ロング動画の切り出し+単発雑学(「クマが濃く見える朝の習慣」「疲れて見える人の共通点」等)
- ショートの役割は認知と人柄接触。CV導線は必ずロング動画→概要欄→LINE/予約へ
- 50〜60代もショートの視聴比率が急伸しているため、大きい字幕・1メッセージ設計を徹底

## 6. VSEO(YouTube検索)キーワード戦略

50〜60代は「検索してから見る」層のため、タイトル・冒頭発話・説明文・字幕でキーワードを一貫させる。

| 優先度 | キーワード例 | 意図 |
|---|---|---|
| S | クマ取り 50代 / クマ取り 60代 / 目の下のたるみ 50代 | 年齢×悩みのド本命。競合が薄い |
| S | 目の下 たるみ取り 切らない / 切らないクマ取り | 術式の入口ワード |
| A | クマ取り 失敗 / クマ取り 後悔 / クマ取り ダウンタイム | 検討後期・不安系。CV直結 |

| B | 老けて見える 目の下 / 疲れて見える 顔 | 潜在層の入口。ショート向き |

## 7. トンマナ・制作ガイドライン

- **サムネイル**: 大きな文字(15文字以内)、50〜60代の顔・症例、白背景基調で「医療の清潔感」。若年美容系の派手な装飾は使わない
- **話し方**: ゆっくり・断定しすぎない・リスクを必ず添える。「売り込まない誠実さ」がこの層への最大の営業
- **字幕**: フルテロップ・大きめフォント(視聴環境はスマホ+老眼を想定)
- **尺**: ロング8〜15分(この層は長尺の完走率が高い)。冒頭30秒で「誰向けか・何が分かるか」を宣言
- **CTA**: 「まずは概要欄からLINEで相談」など、電話・来院より心理ハードルの低い導線を第一に

## 8. 医療広告ガイドライン・コンプライアンス上の留意点

クリニック公式チャンネルは医療広告規制の対象となり得るため、以下を制作フローに組み込む。

1. **ビフォーアフター(症例)**: 施術内容・標準的な費用・治療期間/回数・主なリスク副作用を動画内および説明文に必ず併記する
2. **患者の体験談**: 治療効果に関する患者本人の体験談は広告では原則NG。患者出演は「当日の流れ」等の事実描写に留め、効果の主観的評価は語らせない
3. **院長自身の整形体験**: 医師本人の経歴・動機として語るのは可。ただし「だからあなたも効果が出る」という誘引表現にしない
4. **最上級表現の禁止**: 「名医」「No.1」「絶対安全」等は使用しない。「症例数6,000件以上(期間明記)」のような事実ベース表現に統一
5. 公開前チェックリストを作成し、全動画で院長+運用側のダブルチェックを行う

## 10. KPIとロードマップ

### フェーズ1: 基盤構築(0〜3ヶ月)

- 動画数: ロング12本+ショート30本(4本柱を一巡)
- KPI: 検索流入比率40%以上 /「クマ取り 50代」等のS群キーワードで検索上位表示
- 旗印動画(院長の整形告白)+完全ガイド動画を公開し、チャンネルの世界観を固定

### フェーズ2: 検索資産化(4〜6ヶ月)

- KPI: 登録者3,000人 / 月間視聴時間の伸長 / 概要欄LINE登録 月30件
- 視聴データからペルソナA/Bの反応差を分析し、当たり企画へ制作比重をシフト

### フェーズ3: CV最大化(7〜12ヶ月)

- KPI: 登録者10,000人 / YouTube経由カウンセリング予約 月20件以上
- 来院者アンケートに「YouTubeを見たか」を追加し、間接CVを必ず計測
- 当たり動画のテーマをホームページのコラム・InstagramのリールへN次展開

### 成功の定義

登録者数ではなく **「YouTube経由の50〜60代初診カウンセリング数」** を最上位KPIに置く。この層は視聴単価(1視聴あたりの来院期待値)が若年層より圧倒的に高く、少ない再生でも経営インパクトが出る。

## 11. まとめ

- クマ取り市場はレッドオーシャンだが、**「50〜60代 × はじめての美容医療 × 不安解消・伴走型」**のポジションは全国的に空白であり、東海圏では完全に無競合
- MEMOTOは①目元特化6,000症例、②50〜60代に必須の裏ハムラまで揃う術式、③**院長自身の整形経験**という、このポジションを取るための資産をすべて持っている
- 50〜60代は検索起点・長尺完走・高LTVという「小規模チャンネルでも勝てる」特性を持つ層であり、VSEO主導の資産型運用と相性が最も良い
- 最初の一手は「旗印動画(院長の整形告白)」+「50代のクマ取り完全ガイド」の2本。ここでチャンネルの存在理由を宣言する
