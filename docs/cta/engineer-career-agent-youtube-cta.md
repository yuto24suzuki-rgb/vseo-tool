# エンジニア正社員転職エージェント YouTube CTA台本(A/Bテスト用)

## 前提

- **ターゲット**: 正社員転職を考えているエンジニア(SES・受託 → 自社開発、年収アップ志向層を含む)
- **ゴール**: 概要欄のLINE登録 → 年収診断 → キャリアパートナーとの無料相談
- **尺**: 各案 10〜15秒(ナレーション速度 約6〜7文字/秒を想定)
- **必須要素**:
  1. 概要欄のLINEから年収診断ができる
  2. 優秀なキャリアパートナーが1対1で相談に乗る
  3. 実際の転職支援者のBefore/After(実績)

---

## A案:年収診断・即行動型(約13秒/91文字)

> エンジニアの皆さん、自分の適正年収、知っていますか?
> 概要欄のLINEから、たった30秒で年収診断ができます。
> 今の市場価値を知ることが、年収アップの第一歩。
> 忘れる前に、今すぐ概要欄をチェック。

- **狙い**: 「30秒で終わる」の手軽さ+「今その指で」型の即時行動喚起(参考②の型)
- **テロップ案**: 「LINEで30秒 年収診断」/「概要欄をチェック👇」

---

## B案:Before/After実績型(約13秒/86文字)

> 年収400万のSESエンジニアが、自社開発企業へ転職して年収650万に。
> こうしたリアルな転職事例を、LINEで多数公開中です。
> あなたの伸びしろも、概要欄のLINEから30秒の年収診断で確かめてください。

- **狙い**: 具体的な数字のBefore/Afterで「自分もいけるかも」を喚起(社会的証明)
- **テロップ案**: 「SES 400万 → 自社開発 650万」/「事例多数 → LINEで公開中」
- **注意**: 数字は実際の支援実績に差し替えること。画面にB/Aの実例カードを表示すると効果大。

---

## C案:キャリアパートナー相談型(約14秒/95文字)

> 転職するか、まだ迷っていても大丈夫。
> エンジニア転職を熟知したキャリアパートナーが、1対1であなたの相談に乗ります。
> まずは概要欄のLINEから、30秒の年収診断へ。
> 相談まで、すべて無料です。

- **狙い**: 「迷っていてもOK」で心理的ハードルを下げる(参考③の型)+無料の明示
- **テロップ案**: 「転職迷い中でもOK」/「1対1相談 すべて無料」

---

## D案:損失回避・総合型(約15秒/100文字)

> 今の会社にいて、5年後の年収は上がりそうですか?
> 概要欄のLINEでは、30秒の年収診断に加え、実際の転職者のBefore/After事例も配信中。
> 優秀なキャリアパートナーへの無料相談も、すべてLINEから。
> 概要欄をチェック。

- **狙い**: 損失回避のフック+3つの提供価値をすべて盛り込んだ全部載せ型(参考①の特典列挙の型)
- **テロップ案**: 「①年収診断 ②転職事例 ③無料相談」/「すべて概要欄のLINEから」

## A/Bテスト運用メモ

| 項目 | 推奨 |
|---|---|
| 比較単位 | CTA以外(本編・サムネ・冒頭)は同一条件にし、CTAのみ差し替え |
| 計測指標 | ①CTA区間の視聴維持率(離脱率) ②概要欄クリック率 ③LINE友だち追加数 ④年収診断完了数 |
| 流入計測 | 案ごとにLINEの流入経路パラメータ(または別リンク)を分け、動画単位でどのCTAか特定できるようにする |
| テスト順序 | まず A(即行動)vs B(実績)で訴求軸を特定 → 勝者に C の「迷っていてもOK」要素を足して再テスト |
| 判定期間 | 各案 最低2〜4週間 or 十分なインプレッションが溜まるまで。1変数ずつ検証 |
| 配置 | 動画終盤+可能なら中盤にも短縮版(5秒)を挿入してみる |

## ナレーション収録時のポイント

- 「概要欄」「LINE」「30秒」「無料」はゆっくり・強めに発音
- CTA中は画面にLINE登録画面のモックアップ or B/A事例カードを表示
- 最後のカット(エンドカード)に「概要欄はこちら👇」の矢印を2〜3秒残す
