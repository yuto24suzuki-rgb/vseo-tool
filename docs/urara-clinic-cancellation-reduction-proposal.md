# URARAクリニック カウンセリング予約キャンセル率低下施策 提案書

作成日: 2026-08-14
目的: カウンセリング予約後〜来院までのキャンセル（無断キャンセル・事前キャンセル）を減らす

---

## 1. 施策の全体像

- **何をするか**: カウンセリング予約完了後の「ありがとうございました」ページ（サンクスページ）に YouTube 動画を埋め込み、来院意欲を高めてキャンセルを防ぐ
- **なぜサンクスページか**: メール・LINE配信は開封されない可能性があるが、サンクスページは予約完了者が **100% 通過するページ** のため、確実に接触できる
- **動画の役割**: 予約直後の「意欲が最も高い瞬間」に、(1) 来院への期待を具体化し、(2) 不安を取り除き、(3) 「当日行く理由」をもう一つ追加する

### キャンセルが起きる心理（カウンセラーインタビューからの逆算）

| 予約後に起きること | 対応する動画の役割 |
|---|---|
| 「また失敗するかも」（リバウンド経験者が多数） | 医療ダイエットは自己流・エステと違い根本治療であることを伝え、「今回は違う」と思わせる |
| 「医療ダイエットって何をされるの？」（初めての人が中心） | 当日の流れを見せて未知の不安を消す |
| 「強引に契約させられそう」 | カウンセラー本人が顔を出し、無理な勧誘はしないと明言する |
| 「行っても意味あるのかな」（意欲の減衰） | **InBody測定** という「カウンセリングに行くだけで得られる価値」を提示する |

---

## 2. 撮るべき動画の提案

### 【最優先】本命動画: 「ご予約ありがとうございます」動画（2分30秒〜3分）

サンクスページは一度しか見られないため、**1本に必要要素を統合した動画**を最優先で制作する。
出演はカウンセラー本人（当日会う人の顔が見えることが最大の不安解消になる）。

#### 構成案（台本レベル）

| 時間 | パート | 内容 | 根拠（インタビューシート） |
|---|---|---|---|
| 0:00–0:20 | ご挨拶 | カウンセラー本人が顔出しで「ご予約ありがとうございます。当日担当する◯◯です」 | 会う人が分かると来院ハードルが下がる |
| 0:20–1:00 | **InBody訴求** | 「当日はまず InBody で内臓脂肪レベル・筋肉量・体脂肪量を測定します。ご自身の体の"今"が数字で見えます」— サンプルの結果シートを画面に映して見せる | InBodyの数値見える化で現状の深刻さを自覚し、意欲が高まる（クライアントも同意見） |
| 1:00–1:40 | 共感パート | 「自己流やエステで頑張ったのにリバウンドした、という方が当院には最も多くいらっしゃいます。それは意志の弱さではなく、脂肪細胞の数が減っていないから」 | リバウンド経験者多数・女性の約8割がエステ経験者 |
| 1:40–2:10 | 医療の根拠 | 「当院は薬に頼りきりにならず、脂肪冷却などの医療機器で脂肪細胞そのものにアプローチします。見た目だけでなく、内臓脂肪を落として"肥満を治す"根本治療です」 | GLP-1の副作用・依存への懸念、脂肪冷却への高い期待、「美容→健康・治療」への意識転換が刺さる |
| 2:10–2:40 | 不安解消・締め | 「カウンセリングでは無理な勧誘は一切しません。InBodyの結果を見て、ご自身に必要かどうかを一緒に考える時間です。気になることをメモしてぜひお持ちください。お会いできるのを楽しみにしています」 | 契約圧力への警戒を解き、「行くだけで価値がある」と再確認させる |

**キーメッセージ**: 「カウンセリング = 売り込みの場」ではなく「InBodyで自分の体を知れる場」に再定義する。これが"当日行く理由"になり、キャンセルの機会費用を作る。

### 【第2弾以降】補強動画シリーズ（サンクスページ下部 or 今後のLINE活用向け）

1. **「なぜエステやGLP-1だけではリバウンドするのか」解説動画（約2分）**
   - 脂肪細胞の数・サイズの話と、脂肪冷却が細胞自体を破壊する仕組みを図解
   - エステからの乗り換え層・GLP-1で効果が出なかった経験者に刺さる
2. **卒業生インタビュー動画（約2分）**
   - 「治療終了後もリバウンドせず維持できている」人の声。属性別に3パターンあると理想:
     - 男性: 3ヶ月で結果を出した短期集中型（タイパ・コスパ訴求）
     - 女性: 理想体型を達成した4〜6ヶ月継続型
     - 中高年: 更年期で自力では痩せられなかった → 体質から改善した例
3. **InBody結果の見方解説動画（約90秒）**
   - 内臓脂肪レベル・骨格筋量の読み方を事前に予習してもらう。当日のカウンセリングの納得感も上がる

## 3. 見せる場所と実装

### 主配置: カウンセリング予約完了サンクスページ

- ページ上部（ファーストビュー内）に YouTube 埋め込み
- 動画上に一行コピーを添える:
  > **「ご予約ありがとうございます。当日はまず InBody で、あなたの内臓脂肪と筋肉量を無料測定します。2分半だけ、当日の流れをご覧ください」**
- 埋め込み設定の推奨:
  - `rel=0`（関連動画に他クリニックが出るのを防ぐ）
  - 自動再生はミュート必須になるため非推奨。サムネイルにカウンセラーの顔＋「当日の流れ」テキストを入れてクリックを促す
  - 限定公開（unlisted）で運用すれば検索経由の文脈外流入を防げる

### 補足: メールを使わない判断について

開封されない可能性を踏まえサンクスページ集中は妥当。ただし将来的には、**予約リマインドLINE（前日送付）に同じ動画リンクを再掲**すると、予約〜来院の間隔が長い人の意欲減衰に二重で効く（新規制作コストゼロで流用可能）。

## 4. 効果測定

| 指標 | 取得方法 |
|---|---|
| キャンセル率（KGI） | 予約数に対する来院数を月次で比較（施策前3ヶ月平均 vs 施策後） |
| 動画再生率・視聴維持率 | YouTube アナリティクス（サンクスページ表示数と再生数の比率） |
| 定性変化 | カウンセラーへのヒアリング「動画見ました」「InBody楽しみにしてました」の発言有無 |

視聴維持率が途中で大きく落ちる箇所があれば、その尺・構成を次回撮影で改善する。

4. 計測開始（施策前のキャンセル率をベースラインとして先に記録しておく）
