# URARAクリニック カウンセリング予約キャンセル率低下施策 提案書

作成日: 2026-08-14（第3版）
目的: カウンセリング予約後のキャンセル（主因: 競合との価格比較負け）を、価格ではなく患者様のインサイトに訴求する動画で防ぐ

提案は **①全体設計（どこで見せるか）** と **②動画企画（何を撮るか）** の2軸。

---

## 1. 全体設計 — 予約完了直後の2つの接点に動画を差し込む

予約完了の瞬間は意欲が最も高く、かつ競合比較が始まる前のタイミング。ここで確実に動画に接触させる。

| 接点 | 差し込み方 | 役割 |
|---|---|---|
| **① カウンセリング予約完了画面（サンクスページ）** | 動画リンク（またはYouTube埋め込み）をファーストビューに配置 | 予約完了者が**100%通過する**ページ。最初の接触点として最重要 |
| **② カウンセリング予約完了メール** | 同じ動画リンクを本文上部に差し込み | 予約完了メールは通常のメルマガと違い**開封率が高い**（予約内容の確認のため必ず開かれる）。サンクスページを閉じた後・来院までの期間に見返される受け皿になる |

- 2接点とも**同じ動画（同じリンク）**を使う。制作コストを増やさず接触回数を2倍にする
- サンクスページ・メールとも、動画リンクの上に一行コピーを添える:
  > 「ご来院の前に、院長から3分だけ——**"医療ダイエットはリバウンドするって本当？"** にお答えします」
- 実装の推奨: YouTube限定公開、`rel=0`（関連動画に競合を出さない）、サムネイルは院長の顔＋タイトルテキスト

---

## 2. 動画企画 — 3本構成

3本は独立ではなく、**「リバウンドの不安を解く（1本目）→ 解決手段の豊富さを見せる（2本目）→ 自分ごと化させて来院理由を作る（3本目）」**という流れで1セット。サンクスページ・メールでは1本目をメインに置き、2・3本目を続けて見られる導線（再生リスト）にする。

### 動画1【本命】: 「医療ダイエットはリバウンドするって本当？」

- **タイトル候補**: 「URARAクリニックはなぜリバウンドしないのか」／「医療ダイエットはリバウンドするって本当？」
  - 推奨は後者。疑問形は「GLP-1だけで効果が出なかった」「少し痩せてすぐ戻った」経験者が抱く疑念そのものであり、自分の不安を代弁されたと感じてクリックされやすい
- **話者**: 院長（営業ではなく医師の医学的な話として聞かせるため)
- **尺**: 約3分
- **内容（構成案）**:
  1. 共感の導入 — 「当院に来られる方のほとんどが、自己流・ジム・エステ・痩せる注射で一度うまくいかなかった方です。それは意志の弱さではありません」
  2. リバウンドの正体 — 「食事制限や薬で体重を落としても、**脂肪細胞の数は減っていない**。GLP-1をやめると戻るのはこのため」
  3. URARAがリバウンドさせないための施策 — ①脂肪冷却などで脂肪細胞そのものを減らす、②十分な回数と期間をやり切る設計、③治療終了後も維持できるトータルバランスの体づくり
  4. 締め — 「私たちは見た目の美容ではなく、内臓脂肪を落として肥満を治す"治療"をしています」
- **突いているインサイト**: 「もう二度と失敗にお金を使いたくない」。価格に一切触れずに"失敗しない選び方"の判断基準（回数・期間・終了後の維持）を渡すことで、安い競合プランとの比較を無力化する

### 動画2: 「URARAで使える医療機器 全部見せます」（既存"医療ダイエット完全解説"動画の再編集）

- **制作方法**: 新規撮影なし。既存の完全解説動画から機械紹介パートを切り出して再編集（低コスト・短納期）
- **尺**: 2〜3分に凝縮
- **内容**: 脂肪冷却をはじめ、URARAで使える機械を一通り見せる。各機械が「何に効くか」を一言ずつ
- **突いているインサイト**:
  - 「薬に頼りきりになりたくない」（GLP-1の副作用・依存への懸念）→ 機械の選択肢の多さが安心材料になる
  - 「どの機械を何回受けられるか」で他院と比較する行動 → 機械のラインナップを先に見せることで、内容の濃さの比較でURARAが有利になる
- **動画1との接続**: 動画1で語った「脂肪細胞そのものを減らす」の具体的な手段を見せる役割

### 動画3【ブラッシュアップ版】: InBody訴求 — 「あなたが痩せられない本当の理由、検査で分かります」

「InBodyで体の状態を検査しましょう」だけではフックにならない、という課題認識に同意。理由は、患者様にとってInBodyは目的ではなく手段であり、**「測りましょう」は行動の提案であってインサイトへの回答になっていない**から。

ブラッシュアップの方向: **「検査のお誘い」から「あなたが痩せられない原因の診断」に転換する**。

- **タイトル候補**:
  - 「あなたが痩せられない本当の理由、体重計では分かりません」（推奨）
  - 「その体重、脂肪ですか？筋肉ですか？」
  - 「ダイエットの前に、検査を。— 隠れ内臓脂肪の話」
- **話者**: 院長
- **尺**: 90秒〜2分
- **内容（構成案）**:
  1. フック — 「体重が同じでも、リバウンドする体としない体があります。違いは体重計には映りません」
  2. 原因の提示 — 痩せられない・リバウンドする原因は3つの数字に出る: **内臓脂肪レベル／骨格筋量／基礎代謝**。「更年期やストレスで急に太った方は、ほぼ例外なくこのどれかに原因があります」
  3. サンプルのInBody結果シートを画面に映し、「この方の場合、体重は標準でも内臓脂肪レベルが…」と1例だけ読み解いて見せる（読み解きの面白さ＝続きを自分で体験したくなる）
  4. 締め — 「カウンセリング当日、この検査を無料で行います。**まずは治療を決める前に、あなたの"痩せられない原因"を知りに来てください**」
- **突いているインサイト**: 「自力ではもうどうにもならない（けど原因が分からない）」。原因不明の不安に「原因は数字で特定できる」と答える
- **この動画の戦略的役割**: 来院の意味を「契約するかどうか決めに行く場」から「**自分の体の原因を検査しに行く場**」に書き換える。契約プレッシャーが消えるので来院ハードルが下がり、かつ検査というフレーミングは「美容→健康・治療」の意識転換（ヒアリングで最も刺さると確認済み）とも一致する。クライアントと話していた「InBodyの見える化で意欲が高まる」効果を、来院前のフックとして前倒しで使う設計

## 3. 効果測定

| 指標 | 取得方法 |
|---|---|
| キャンセル率（KGI） | 予約→来院率を月次比較（施策前3ヶ月平均をベースラインとして先に記録） |
| 接点別の視聴 | サンクスページとメールでリンクにパラメータを分け、どちら経由の再生かを分離計測 |
| 再生率・視聴維持率 | YouTubeアナリティクス。離脱集中箇所は次回撮影で改修 |
| 定性検証 | カウンセラーにヒアリング: 来院者が「動画見ました」「検査してもらえるんですよね」等、動画由来の発言をしているか |

---

## 4. 次のアクション

1. 動画2の再編集から着手（既存素材のため最速で公開可能）
2. 動画1・3の台本を院長と確定 → 同日にまとめて撮影（院長出演・白衣・診察室背景、InBody結果シートのサンプルを小道具に用意）
3. 3本を再生リスト化し、サンクスページとメールに同一リンクで差し込み
4. 施策前キャンセル率を記録 → 計測開始
