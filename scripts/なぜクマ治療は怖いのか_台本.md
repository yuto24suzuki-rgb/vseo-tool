# 台本：なぜクマ治療は怖いのか？【クマ取り天元先生】

- **テーマ:** なぜクマ治療は怖いのか？ — 怖さの正体を分解し、ROOTSの研究成果で1つずつ解消する
- **想定尺:** 8〜10分
- **構成方針:** 冒頭で「怖さの正体」を3つに言語化して共感を最大化 → 1つずつ順番に潰す → 恐怖が「期待」に変わって終わる流れ

---

## 0. オープニング／フック（0:00〜）

**天元先生（カメラ目線）:**

「クマ取り、正直…怖くないですか？」

実はこの質問、カウンセリングで僕が逆に患者さんに聞くことがあるんです。すると、ほとんどの方がこう答えます。

「怖いです」と。

でも面白いことに、「何が怖いんですか？」と聞くと、多くの方が言葉に詰まるんですね。

**（テロップ：怖さの正体、言えますか？）**

これはつまり、**「よくわからないから怖い」** という状態なんです。人間は、正体のわからないものを一番怖がる生き物です。お化け屋敷が怖いのは、どこから何が出てくるかわからないから。逆に、種明かしされたお化け屋敷は怖くないですよね。

だから今日は、クマ治療の「種明かし」をします。

僕が6000件以上のクマ治療とカウンセリングをしてきた中で、皆さんが怖いと感じるポイントは、実は次の3つに集約されます。

**（テロップ：クマ治療が怖い理由 3つ）**

1. **目の周りを触られる恐怖** —「眼球を傷つけられたらどうしよう」
2. **痛みへの恐怖** —「麻酔とか手術って痛いんじゃないの？」
3. **完成への不安** —「本当に綺麗になるの？失敗しない？」

大きく腫れた症例の写真、SNSで飛び交う「失敗」「後悔」という言葉。それを見て怖くなるのは、当たり前です。

でも、ROOTSはこの3つの怖さを**最大限なくすための研究**をずっと続けてきました。今日はその研究の成果を、全部お伝えします。この動画を最後まで見終わる頃には、皆さんの「怖い」の正体が消えているはずです。

---

## 1. 恐怖その①：目の周りを触られる恐怖（1:30〜）

**（テロップ：恐怖① 眼球へのダメージ）**

まず1つ目。目の周りを扱う施術なので、

「眼球に傷がついたらどうしよう」
「失明とかするリスクもあるんじゃない？」

と考える方、いらっしゃると思います。目は一生モノですから、この不安は当然です。

でも、これはROOTSがクマ取りを**どういう手順で行っているのか**を見ていただければ、そもそもこんな不安は起きてきません。実際にお見せします。

**【眼球に触れるはずがないという説明パート】**

- （映像指示：施術手順の図解 or 実際の器具・保護の様子）
- ポイント：手順のどの段階でも、眼球と施術部位の間に物理的な「壁」があることを視覚的に見せる
- 「触ろうと思っても触れない」という構造であることを強調

**天元先生:**

いかがだったでしょうか？

つまりROOTSでは、**眼球には触れたくても触れられない「構造」を作りながら**施術を行っています。「気をつけているから大丈夫」ではなく、「構造上、触れられない」。ここが大事なポイントです。

### 白目の充血について

「でも、他のクリニックで術後に白目が充血している症例を見かけるよ？」という方もいるかもしれません。

実はあの充血も、**とある工夫をすることで理論上完全にゼロにできます。**

いつもならここで手の内を全部説明するんですが……すみません、ここだけは**企業秘密**とさせてください。長年の研究の末にたどり着いたものなので。

でも、結果は隠しません。その工夫の結果、**ROOTSでは白目の充血は起きません。** 実際に術後1週間の経過を2例、見てみましょう。

**【1週間経過の症例 2例】**

- （映像指示：術前 → 直後 → 1週間後の順で比較。白目のアップも入れる）
- （テロップ：術後1週間／白目の充血なし）

**天元先生:**

どうでしょうか？綺麗なお目元になったのはもちろん、白目の充血もなく、ダウンタイムも最小限に抑えられているのがわかっていただけたと思います。

「目に傷がつきそうで怖い」という1つ目の恐怖はこれで消え去ったのではないでしょうか？

## 2. 恐怖その②：痛み（4:00〜）

**（テロップ：恐怖② 痛み）**

では、次の怖さ。「痛み」です。

痛みについては、以前**対策を徹底的に解説した動画**があるので、詳しくはそちらをぜひ見ていただきたいのですが──

**（画面：該当動画のサムネイルを表示＋カード誘導）**

痛みへの恐怖って、突き詰めると「**いつ、どんな痛みが来るかわからない**」という恐怖なんです。冒頭のお化け屋敷と同じですね。

ROOTSクリニックは、6000件の治療経験から、

- 麻酔の成分で何がどう効くのか
- 切開の角度や力加減で、どの瞬間にどんな刺激が出るのか
- 脂肪を移動させるときに、どんな感覚が出るのか

つまり、**クマ治療のどの工程で、どんな痛みが出る可能性があるのかを、全部知っています。**

知っているからこそ、痛みが出る前に**先回りして**麻酔や処置を組み立てられる。痛みを「我慢してもらう」のではなく、「そもそも出させない」。これがROOTSの痛み対策です。

**（テロップ：痛みは我慢させない、先回りして出させない）**

その結果どうなったか。これまで6000件のクマ治療を行ってきましたが、**術後に痛みで困って相談に来た方は、1人もいません。**

**（テロップ：6000件中、痛みの相談 0人）**

6000件でゼロ。これは偶然では出せない数字です。2つ目の恐怖「痛み」も、これで種明かし完了です。

## 3. 恐怖その③：完成がどうなるのか（6:00〜）

**（テロップ：恐怖③ 仕上がりへの不安）**

では最後、「完成がどうなるのか」という不安です。

これは、過去にROOTSクリニックのYouTubeを一度でも見てくださった方であれば、わかってくださるかと思います。**この仕上がりの綺麗さには、とても自信があります。**

**【症例を1例提示】**

- （映像指示：術前→完成の比較をじっくり見せる。ライティング条件を揃えたことがわかる見せ方だと信頼感UP）

### 仕上がりだけでなく「過程」も綺麗に

そしてここが、今日一番お伝えしたいことかもしれません。

ROOTSは仕上がりだけではなく、**そこに至る過程──つまりダウンタイムの綺麗さ**も追求しています。

なぜか。ダウンタイム中の見た目こそが、不安の一番の源だからです。腫れた自分の顔を鏡で見て「本当に綺麗になるのかな…」と毎日不安になる。

だからROOTSでは、施術の段階からダウンタイムを減らすための様々な工夫をしています。ダウンタイムが軽ければ、鏡を見るたびに感じるのは不安ではなく、

**「ここから、どこまで綺麗になるんだろう」**

という**期待感**に変わります。同じ1〜2週間でも、不安で過ごすのか、楽しみで過ごすのか。まったく違う時間になります。僕は皆さんに、後者で過ごしてほしい。

**（テロップ：不安のダウンタイム → 期待のダウンタイム）**

## 4. まとめ／クロージング（8:00〜）

**天元先生:**

いかがだったでしょうか？今日の種明かしをまとめます。

**（テロップ：まとめ）**

1. **眼球への恐怖** → 触れたくても触れられない「構造」で施術。白目の充血もゼロ。
2. **痛みへの恐怖** → どの工程で何が起きるか全部わかっているから、先回りで出させない。6000件で痛みの相談ゼロ。
3. **完成への不安** → 仕上がりに自信があるのはもちろん、ダウンタイムの綺麗さまで追求。不安ではなく期待で過ごせる。

冒頭で言った通り、怖さの正体は「わからないこと」です。ここまで見てくださった皆さんは、もうクマ治療の中身を知っています。だから、最初に感じていた漠然とした怖さは、かなり軽くなっているんじゃないでしょうか。

それでも「まだ少し怖い」という方。それで大丈夫です。最後に残った不安は、あなた自身のお悩みに合わせた話でしか解消できません。それはカウンセリングの役割です。

少しでも気になっている方は、ぜひ**概要欄のLINE**からカウンセリング予約をしてください。無理に治療を勧めることはありません。まずはあなたの「怖い」の正体を、一緒に言葉にするところからで大丈夫です。

それでは。

## 制作メモ

### この台本で強化したポイント（元構成からの変更点）

| 強化点 | 狙い |
|--------|------|
| 冒頭に「お化け屋敷」の比喩と「怖さ＝情報不足」のフレームを追加 | 動画全体を「種明かし」という一本の軸で貫き、納得感を作る |
| 3つの恐怖を冒頭でナンバリングして予告 | 視聴者が自分の怖さを特定でき、離脱を防ぐ（自分ごと化） |
| 「気をつけているから大丈夫」ではなく「構造上、触れられない」という対比を追加 | 「気をつけます」より遥かに強い安全性の論理として提示 |
| 充血ゼロの企業秘密は「手の内は隠すが結果は隠さない」と整理 | 秘密にすることの不信感を、症例提示でカバーする流れを明示 |
| 痛みパートを「いつ来るかわからない恐怖」と再定義し、冒頭の比喩と接続 | 「先回り麻酔」の価値が論理的に伝わる |
| クロージングで「残った不安はカウンセリングでしか解消できない」と橋渡し | LINE誘導が営業ではなく自然な次のステップになる |
